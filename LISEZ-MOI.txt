CENI Hors-ligne MOBILE (saisie 1) — application web (PWA)

1) MISE EN LIGNE (une seule fois) — GitHub Pages, gratuit, https :
   - Créez un compte sur github.com, puis « New repository » (public), ex. nom : ceni-hl
   - « Add file » > « Upload files » : envoyez TOUS les fichiers de ce dossier (index.html, app.js, kv.js,
     tadidy.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png), puis « Commit changes ».
   - Settings > Pages > Source : « Deploy from a branch » > Branch : main, dossier /(root) > Save.
   - Après 1-2 minutes, l'adresse est : https://VOTRE-NOM.github.io/ceni-hl/

2) INSTALLATION SUR LE TÉLÉPHONE :
   - Ouvrez cette adresse dans Chrome (avec Internet, une première fois).
   - Menu ⋮ > « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
   - Ensuite elle marche SANS Internet. Les données restent dans l'application.

3) IMPORTER LES IMAGES (le téléphone ne sait pas choisir un dossier) — 2 méthodes :
   A. ZIP (recommandé) : dans l'application « Fichiers », compressez le dossier des carnets (ou un carnet) en .zip.
      Puis ☰ Menu > « Importer un fichier ZIP ». Les noms des dossiers donnent les n° de carnet (modifiables).
   B. Images : ☰ Menu > « Importer des images », cochez plusieurs images (ou « tout sélectionner » dans le dossier).
      Tapez d'abord le n° du carnet (champ en haut) : il sera proposé pour ces images.

4) UTILISATION :
   - 📚 = liste des carnets et des feuilles faites. Le n° de feuille s'écrit tout seul d'après le nom de l'image.
   - Une image couchée (paysage) est redressée automatiquement ; boutons ⟲ ⟳ pour corriger.
   - ⟳ Synchro interne : copie de sécurité dans l'application. ⬇ Exporter TOUT : un seul fichier pour tous les carnets,
     à importer dans l'extension « CENI Hors-ligne » sur le PC (bouton ⬆ Importer).
   - Ne videz pas les « données de site » de Chrome et ne désinstallez pas l'application avant d'avoir exporté.
